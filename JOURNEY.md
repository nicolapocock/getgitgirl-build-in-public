## 2026-09-02 — Set up the growth OS

- Watched Greg Isenberg's "Marketing Engineer" episode and turned it into a repeatable
  workflow (a scaffold + templates + the 30-day plan).
- Stood up a private growth OS repo for three brands: Think Big Media (my agency —
  this is the North Star), a client practice, and getgitgirl itself.
- Each repo starts the same way: a NORTH-STAR file, and the "painfully simple v1" —
  ~20 real customer notes, a founder voice guide, and one `market-truth.md` memo that
  has to carry receipts (quotes, links, counts), not vague summaries.

**Learned:** the folder structure isn't the hard part — the discipline is. "Receipts,
not summaries" and "measure pipeline, not activity" are the two rules everything else
hangs off.

**Next:** fill `01-customer-truth/` for Think Big Media from real discovery-call
notes, and run the first `market-truth.md` job — "tell me what's changed, show me the
receipts, suggest one test that could create pipeline this week."
