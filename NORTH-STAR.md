# North Star — becoming a marketing engineer (in public)

_Started 2026-09-02._

## The goal

Make the full move from traditional / digital / social marketer to **marketing
engineer** — someone who turns market signal into pipeline using AI agents, data,
code and taste — and show the working the whole way.

## What I'm building toward

- A **growth OS** for each brand I work on (a repo that holds the marketing memory so
  AI agents stop starting from scratch every week).
- Growth systems that run end-to-end with a human approval gate: customer-truth,
  content engine, outbound signal engine, creative testing, AI-search visibility, a
  weekly cockpit.
- Every agent written like a job description — data source, cadence, filters, output,
  approval, the metric that matters (pipeline, not activity), where it writes results.

## How I'll know it worked

- A real case study: audited a brand's growth, built the customer-truth repo, found
  one high-intent pain, turned it into one system, and it moved a real number.
- The workflow grows getgitgirl itself — a small account — measurably.

## The rule I'm holding

The tools will keep changing. The workflow is the skill. Judgment about what to point
the agents at is the moat.
